# Project Overview

The Financial Fraud Risk Intelligence Assistant is an educational end-to-end data project.
It uses PaySim synthetic financial transactions to demonstrate data engineering, machine learning,
LLM explanation, RAG, dashboards, and AWS deployment.

## What the assistant does

The risk service scores a transaction, explains the score with SHAP reasons, and answers
questions about the project from this knowledge base. Every answer from the knowledge base
cites the document and the section it came from.

## What it is not

It is not a production decision system. It never approves, declines or blocks anything, and it
does not give financial, lending, legal, tax or investment advice.
